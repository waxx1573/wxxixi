# Smart Core

> 状态：线上已停用。本目录保留历史实现、迁移证据和回退参考，不代表当前微信主链路仍加载本插件。

将 Smart Group Bot 的平台无关能力逐步移植到 AstrBot 插件层。Akasha 只负责微信接入，本插件负责决策提示、审核边界、回复策略和后续记忆/RAG 扩展。

当前版本：提供一个 `pipi` 原生聊天人格，以及独立的 Smart 内部决策、审核和管理意图提示词；同时提供群聊回复边界、重复消息与冷却状态、`/smart状态` 命令，以及可视化群管理和模型路由配置。

群管理页支持新增、删除、命名、启停微信群，并控制 PPBot 是否参与回复及回复方式。保存后会同步微信群管理插件的白名单和群运行状态。群 ID 必须使用微信桥接上报的稳定 ID。
