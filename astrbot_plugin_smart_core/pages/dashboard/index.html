Smart 能力总览

Akasha 只负责微信接入，Smart Core 在 AstrBot 内统一处理决策、审核、记忆和回复。

关闭后由 AstrBot 使用原生回复流程。

群管理

从微信桥接自动读取群聊。选择群后即可设置该群的回复和审核策略。

群 ID由系统自动绑定，不需要手动填写。
微信 群管理PPBot 回复回复方式审核级别

智能决策

在生成回复前判断消息属于回复、忽略、命令或需要审核。

内容审核

在回复前执行基础安全边界，后续可扩展关键词、正则和 LLM 审核。

回复策略

控制回复概率、重复消息和模型失败后的行为。

0 到 1，1 表示每条符合条件的消息都回复。

记忆与 RAG

为后续接入短期上下文、长期记忆、知识库和向量检索预留统一开关。

模型路由

按任务选择 AstrBot provider。这里只保存 provider ID，不显示或修改 API 密钥。
