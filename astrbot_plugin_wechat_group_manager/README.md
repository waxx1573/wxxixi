# astrbot_plugin_wechat_group_manager

面向 Akasha-WeChat / WeFlow 链路的 AstrBot 微信群管理插件。

当前能力包括稳定 ID管理员白名单、群级运行状态、回复模式、静默时段、关键词、软审核队列、管理员公告和操作审计。管理命令以 `/wx` 开头；权限判断使用协议层稳定发送者 ID，显示名只用于展示。

公告格式：`/wx 公告 <稳定群ID|当前|全部> <内容>`。目标只接受 `allowed_group_ids` 中的稳定群 ID；`全部` 只展开当前允许列表，不按群名猜测。每个目标单独调用 AstrBot 原生 OneBot `send_group_msg`，并记录提交结果、目标、操作者和内容摘要；桥接层是否完成微信实际送达仍需真实消息回读验收。

配置文件或数据库保存成功不代表所有运行内存已经刷新。每项配置仍需按“持久化、内存加载、真实业务行为”三层验收。
